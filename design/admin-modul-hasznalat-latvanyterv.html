Technika röviden (döntés után így fejlesztenénk)

1. SQL: új module_views tábla (felhasználó, modul, nap — fejenként naponta egy sor, max. ennyit tárolunk) + RLS; csak a szerver ír.
2. Mérés: a modul-oldalak betöltésekor egy könnyű, natív API-hívás (/api/track/module-view) — külső eszköz nélkül; admin és sales is naplózódik, a szűrő dönt.
3. Lekérdezés: /api/admin/module-usage — a usage_history + module_views + module_favorites + irodai tagságok összesítése, időszak / forrás / mód / szerepkör szűrővel.
4. Felület: második fül a Felhasználók oldalon; Új regisztrálók → Modulok → Felhasználók (TOP 5) → Irodák; részletek felugró ablakban; CSV.
